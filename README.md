# CELF-5-NL Digitale Afname

Afname-app voor Logopedie Sophie. Het kind tikt het plaatje aan op het scherm, de app scoort aan de hand van de antwoordsleutel en telt de ruwe score op. Sophie kijkt mee en kan elke score aanpassen.

Deze repository bevat alleen de code, zonder testmateriaal. De PDF's van de stimulusboeken laadt Sophie zelf één keer in de app in. Ze blijven lokaal op haar toestel en in de bewaarmap die ze koppelt.
